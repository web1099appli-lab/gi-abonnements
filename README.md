# GI-Abonnements

**Application Windows gratuite pour suivre ses abonnements, leurs coûts et leurs échéances.**

GI-Abonnements recense vos abonnements et contrats récurrents (logiciels, assurances, hébergements,
maintenance de sites, téléphonie…), calcule leur coût mensuel et annuel, et signale ceux qui arrivent
à échéance. Vos données restent sur votre ordinateur : l'application ne se connecte jamais à internet.

## Télécharger

➡ **[Dernière version](https://github.com/web1099appli-lab/gi-abonnements/releases/latest)**

| Fichier | Usage |
|---|---|
| `GI-Abonnements-Setup-x.y.z.exe` | Installeur conseillé (raccourcis Bureau et menu Démarrer) |
| `GI-Abonnements-Portable-x.y.z.exe` | Version sans installation (clé USB…) |
| `SHA256SUMS.txt` | Empreintes pour vérifier l'intégrité des fichiers |

Système : Windows 10 ou Windows 11 (64 bits). Gratuit.

## Installation

1. Téléchargez l'installeur et double-cliquez dessus.
2. Si Windows affiche « Windows a protégé votre ordinateur » (application non signée par un certificat
   payant), cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**.
3. Lisez les conditions d'utilisation et cochez **J'accepte les conditions d'utilisation**.

## Vos données

- Enregistrées uniquement sur votre ordinateur, dans `%APPDATA%\GI-Abonnements\donnees.json`.
- Sauvegarde et restauration avec les boutons **Exporter (JSON)** et **Importer (JSON)**.
